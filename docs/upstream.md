# Source and cleanup

Imported from https://github.com/nmime/nest-react-boilerplate at
`2e10b3298956b887065e0b87cac23ab57335a397` as one baseline commit.
The upstream MIT license is preserved in `LICENSE`.

This product replaces the enterprise Nx/NRB workspace with three pnpm packages:
one React/Vite frontend, one NestJS/Fastify API, and shared Zod contracts.
Reference applications, mobile, bots, authentication services, notifications,
payment integration, Redis, NATS, S3, Kubernetes, platform generators,
and unrelated specifications/documentation have been removed from the product tree.
